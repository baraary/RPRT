# رادیورپورت (RadioReport) | سامانه هوشمند گزارش‌نویسی تصویربرداری پزشکی

سامانه حرفه‌ای گزارش‌نویسی، آرشیو و چاپ استاندارد گزارش‌های **سونوگرافی، ام‌آر‌آی (MRI) و سی‌تی‌اسکن (CT Scan)** با قابلیت کارکرد **۱۰۰٪ آفلاین (PWA)**، **اشتراک‌گذاری در شبکه داخلی بیمارستان/کلینیک (LAN با دیتابیس SQLite)** و **استقرار آنلاین روی GitHub Pages**.

---

## ۱. ظرفیت ذخیره‌سازی نامحدود (میلیون‌ها گزارش بیمار)
* **موتور IndexedDB دائمی (`navigator.storage.persist`):** استفاده از سقف فضای آزاد هارد دیسک (۶۰ تا ۸۰ درصد فضای درایو سیستم) بدون محدودیت ۵ مگابایتی `localStorage`. با توجه به حجم حدود ۲ کیلوبایت برای هر گزارش متنی، هر ۱۰ گیگابایت معادل **بیش از ۵,۰۰۰,۰۰۰ (۵ میلیون) گزارش** و در سیستم‌های معمولی معادل **بیش از ۳۰ میلیون گزارش بیمار** است.
* **دیتابیس SQLite در شبکه محلی (`data/radioreport_lan.sqlite` در حالت WAL):** ذخیره‌سازی مستقیم روی هارد سرور بدون هیچ سقف تعداد گزارش.
* **پشتیبان‌گیری خودکار روزانه روی پوشه هارد دیسک (File System Access API):** ذخیره خودکار فایل JSON پشتیبان در پوشه دلخواه کامپیوتر.

---

## ۲. راهنمای انتشار آنلاین رایگان روی GitHub Pages

پروژه از پیش با مسیرهای نسبی (`base: './'`) و فایل اتوماتیک **GitHub Actions** (`.github/workflows/deploy-pages.yml`) آماده شده است:

1. یک مخزن (Repository) در گیت‌هاب بسازید و فایل‌های این پروژه را در شاخه `main` قرار دهید (Push یا آپلود).
2. در صفحه مخزن گیت‌هاب، وارد **Settings** و سپس از منوی سمت چپ وارد **Pages** شوید.
3. در بخش **Build and deployment**، گزینه **Source** را روی **GitHub Actions** قرار دهید.
4. گیت‌هاب به صورت خودکار پروژه را Build کرده و در کمتر از ۱ دقیقه، برنامه روی آدرس اینترنتی شما فعال می‌شود:
   `https://<YOUR-USERNAME>.github.io/<REPO-NAME>/`

---

## ۳. راهنمای راه‌اندازی روی سرور محلی بیمارستان / کلینیک (شبکه داخلی LAN)

اگر می‌خواهید در بیمارستان یا مرکز تصویربرداری، **چند کامپیوتر تایپیست** بدون نیاز به اینترنت به یک سرور داخلی متصل شوند و **آرشیو بیماران، قالب‌های پزشکان، بانک جملات و آمار تایپیست‌ها** بین همه سیستم‌ها مشترک باشد:

### گام اول: نصب پیش‌نیاز روی کامپیوتر اصلی (سرور داخلی)
1. نرم‌افزار **Node.js (نسخه LTS)** را از سایت `nodejs.org` دانلود و روی یکی از کامپیوترهای مرکز (که به عنوان سرور در شبکه روشن است) نصب کنید.
2. پوشه پروژه را روی آن کامپیوتر قرار دهید.

### گام دوم: اجرای سرور روی کامپیوتر اصلی
در پوشه پروژه، پنجره ترمینال (Command Prompt یا PowerShell) را باز کرده و دستور زیر را اجرا کنید:

```bash
npm install
npm run build
npm start
```

پس از اجرا، پیغام زیر در ترمینال نمایش داده می‌شود:
```text
============================================================
✅ RadioReport Server Running (SQLite WAL Mode Active)
🖥️  Local Access (This PC):   http://localhost:3000
🌐 Network Access (LAN):     http://192.168.1.100:3000
============================================================
```

### گام سوم: باز کردن پورت ۳۰۰۰ در فایروال ویندوز (فقط یک بار روی کامپیوتر سرور)
برای اینکه سایر کامپیوترهای شبکه بتوانند به کامپیوتر سرور وصل شوند، Command Prompt (CMD) را به صورت **Run as Administrator** باز کرده و دستور زیر را وارد کنید:

```cmd
netsh advfirewall firewall add rule name="RadioReport LAN" dir=in action=allow protocol=TCP localport=3000
```

### گام چهارم: اتصال سایر کامپیوترهای تایپیست‌ها
1. در هر یک از کامپیوترهای دیگر بیمارستان (که به همان مودم، سوئیچ یا شبکه LAN وصل هستند)، مرورگر **Chrome** یا **Edge** را باز کنید.
2. آدرس نمایش داده شده در مرحله دوم (مثلاً `http://192.168.1.100:3000`) را وارد کنید.
3. از بخش **تنظیمات ⬅ اشتراک‌گذاری شبکه محلی (LAN Sync)**، تیک سینک شبکه محلی را فعال نگه دارید تا تمام گزارش‌ها و قالب‌ها در فایل `data/radioreport_lan.sqlite` روی سرور مرکزی همگام‌سازی شوند.
