# رادیورپورت (RadioReport) | سامانه تخصصی گزارش‌نویسی پرتوپزشکی (سونوگرافی، ام‌آر‌آی و سی‌تی‌اسکن)

سامانه هوشمند، سریع و **۱۰۰٪ آفلاین‌پذیر (PWA)** ویژه مراکز تصویربرداری، بیمارستان‌ها و تایپیست‌های رادیولوژی.

---

## ✨ قابلیت‌های کلیدی

- **پشتیبانی از ۳ مدالیته تخصصی با تم رنگی متمایز:** سونوگرافی (آبی آسمانی)، ام‌آر‌آی (نیلی) و سی‌تی‌اسکن (سبز زمردی).
- **مدیریت چند تایپیست و آمار کارکرد دقیق:**
  - انتخاب سریع تایپیست فعال شیفت از نوار بالای صفحه.
  - ثبت خودکار نام تایپیست روی تمام گزارش‌های ذخیره‌شده و چاپ‌شده.
  - داشبورد آمار کارکرد **روزانه، هفتگی، ماهانه و کل دوره** به تفکیک تعداد بیماران (پرونده‌ها) و مجموع بررسی‌های تصویربرداری + خروجی اکسل (CSV).
- **محیط چندتب (Multi-Patient Workspace):** باز کردن همزمان پرونده چند بیمار و انتخاب همزمان چند قالب تصویربرداری برای یک بیمار.
- **قالب‌های آماده و سنجاق‌شده (Pinned Templates):** اجرای فوری قالب‌های پرتکرار هر مدالیته با کلیدهای `F1` تا `F8` و ذخیره تک‌مرحله‌ای گزارش در قالب‌ها.
- **شورتکات‌ها و ماکروهای فوری (Auto-Text Expander):** تایپ کدهایی مانند `.abd` یا `.nl` + کلید `Space` برای درج آنی جملات پرتکرار.
- **بررسی هوشمند املا، نیم‌فاصله و تطابق جنسیت بیمار با آناتومی گزارش (`Alt + C`).**
- **ذخیره خودکار پیش‌نویس موقت هر ۳۰ ثانیه (Crash Recovery):** جلوگیری از پاک شدن گزارش در صورت بسته شدن ناگهانی مرورگر یا قطع برق.
- **چاپ سربرگ رسمی A4:** پشتیبانی از لوگوی اختصاصی مرکز، امضای دیجیتال پزشک، بارکد اصالت‌سنجی `QR` (آنلاین و آفلاین) و خروجی مستقیم `PDF`، `Word` و `HTML`.

## 🚀 نحوه دانلود از گیت‌هاب و اجرای آفلاین در مرکز تصویربرداری

### روش اول: نصب مستقیم به عنوان نرم‌افزار دسکتاپ آفلاین (PWA - پیشنهادی)
1. سامانه را یک بار در مرورگر **Google Chrome** یا **Microsoft Edge** باز کنید.
2. روی دکمه **«نصب آفلاین»** در نوار بالای برنامه (یا آیکون نصب در سمت راست نوار آدرس مرورگر) کلیک کنید.
3. برنامه مانند یک نرم‌افزار مستقل روی دسکتاپ ویندوز/مک نصب می‌شود و به کمک **Service Worker** تمامی فایل‌ها، فونت‌ها، قالب‌ها و دیتابیس محلی را کش کرده و **بدون نیاز به اینترنت** کار می‌کند.

### روش دوم: اجرای محلی از سورس گیت‌هاب (Local Offline Server)
پیش‌نیاز: نصب بودن [Node.js](https://nodejs.org/) (نسخه ۱۸ یا بالاتر) روی سیستم.

```bash
# ۱. دریافت پروژه از گیت‌هاب
git clone <YOUR_GITHUB_REPO_URL>
cd radioreport

# ۲. نصب پکیج‌ها (فقط بار اول نیاز به اینترنت دارد)
npm install

# ۳. ساخت نسخه نهایی آفلاین و اجرای برنامه
npm run build
npm run preview
```

پس از اجرای دستور بالا، برنامه روی آدرس محلی (مثلاً `http://localhost:4173` یا `http://localhost:3000`) بدون نیاز به اینترنت در دسترس است.

## 💾 پشتیبان‌گیری و انتقال اطلاعات بین سیستم‌ها
تمامی قالب‌ها، شورتکات‌ها، پزشکان، تایپیست‌ها و آرشیو گزارش‌ها در حافظه مرورگر (`localStorage`) ذخیره می‌شوند.
برای انتقال اطلاعات از یک کامپیوتر به کامپیوتر دیگر:
1. وارد بخش **تنظیمات** در نوار بالا شوید.
2. روی **«دانلود نسخه پشتیبان (JSON)»** کلیک کنید.
3. در سیستم مقصد، از بخش تنظیمات گزینه **«بازیابی از فایل»** را انتخاب نمایید.
